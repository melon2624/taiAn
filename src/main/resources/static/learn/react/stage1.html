阶段一

React 基础入门：先把页面写活

目标：你能看懂并修改 /learn/js/react-admin-demo.jsx，能用 React 写列表、按钮事件、输入框和简单表单。

1. JSX：在 JavaScript 里写页面结构

JSX 看起来像 HTML，但它本质是 JavaScript 表达式。你需要先习惯两个差异：写 class 要用 className，写动态内容要用 {}。

function Hello() {
  const name = "张三";
  return <h1 className="h3">你好，{name}</h1>;
}

经验：刚学时不要纠结 JSX 原理，先把它当作“更强的 HTML 模板”。等你能写组件了，再回头看编译原理更容易懂。

2. 组件：把页面拆成函数

React 页面不是一大段 HTML，而是一堆组件拼起来。比如后台页面可以拆成 Sidebar、MetricCard、UserForm、UserTable。

function MetricCard({ label, value }) {
  return (
    <div className="metric-card">
      <div>{label}</div>
      <strong>{value}</strong>
    </div>
  );
}

经验：组件不是越碎越好。先按页面区域拆，重复出现两三次后再抽成通用组件。

3. props：父组件把数据传给子组件

props 就像 Java 方法参数。父组件决定数据，子组件负责显示。

<MetricCard label="总用户" value={users.length} />

经验：子组件尽量少知道业务全局，只拿自己要显示的数据。这样组件更好改，也更不容易牵一发动全身。

4. useState：让页面记住变化

HTML 页面刷新前通常是静态的，React 页面靠状态变活。搜索词、表单输入、用户列表、当前筛选状态都可以放进 useState。

const [keyword, setKeyword] = useState("");

<input
  value={keyword}
  onChange={(event) => setKeyword(event.target.value)}
/>

经验：不要直接改状态里的数组或对象。用新数组、新对象替换旧值，比如 setUsers([...users, newUser])。

5. 事件：用户操作触发数据变化

按钮点击、输入框变化、表单提交，本质都是事件。React 的思路是：事件里改数据，数据变化后页面自动重新渲染。

function removeUser(id) {
  setUsers(users.filter((user) => user.id !== id));
}

经验：事件函数命名尽量表达意图，比如 createUser、removeUser、toggleStatus，不要都叫 handleClick。

6. 列表渲染：map、filter 是后台系统基本功

表格来自数组。搜索和筛选来自 filter，渲染来自 map。

{users.map((user) => (
  <tr key={user.id}>
    <td>{user.name}</td>
  </tr>
))}

经验：key 优先用稳定 ID，不要优先用数组下标。后台表格以后会删除、排序、分页，下标容易出问题。

7. 表单：受控组件是 React 的基本姿势

输入框的值来自状态，输入变化时再更新状态，这叫受控组件。它一开始麻烦，但后面做校验、提交、重置会很清楚。

const [form, setForm] = useState({ name: "", role: "编辑" });

setForm({ ...form, name: event.target.value });

经验：表单字段少时可以用一个对象管理；字段很多时再考虑拆组件或引入表单库。
