React Roadmap

从零学 React，到能写管理系统

你已经有 HTML、CSS、JavaScript 基础，所以路线会直接围绕后台系统常见功能展开。

阶段一

React 基础入门

目标是看懂 JSX、会拆组件、会用状态、会写事件、会渲染列表和表单。

  • 组件、props、children
  • useState、事件处理
  • map/filter、条件渲染
  • 受控表单和简单校验
进入阶段一
阶段二

管理系统实战

目标是能做一个常见后台页面：布局、列表、搜索、筛选、新增、删除、接口思维。

  • 后台布局和页面结构
  • 表格、工具栏、统计卡片
  • CRUD 交互和加载状态
  • 组件拆分与数据流
进入阶段二 打开练习项目
阶段三

商业项目能力

先不急着学，作为后续升级路线：工程化、路由、权限、接口封装、部署和规范。

  • Vite、React Router
  • 登录、权限、菜单
  • 接口封装、错误处理
  • 打包部署与项目规范
先看看后续方向

你应该怎么学

学习顺序

  1. 先读阶段一，每学一个点就去改一次练习项目。
  2. 阶段二开始按管理系统功能拆：布局、列表、表单、筛选、删除。
  3. 暂时不要急着上脚手架，先把 React 的“数据驱动页面”想明白。
  4. 阶段二完成后，再进入 Vite、Router、接口封装这些商业项目能力。

老手经验

  • React 最难的不是语法，是想清楚“数据放哪里，谁改数据”。
  • 页面先写死，再抽组件，再加状态，比一开始就设计抽象更稳。
  • 表单、表格、筛选、分页是后台系统的基本功，重复练很值。
  • 看到报错先读第一行和组件名，React 报错通常比你想象的诚实。
