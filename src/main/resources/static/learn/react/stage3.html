阶段三

商业项目能力：先放这里，后面再学

这个阶段不急。等你能写阶段二的管理系统，再进入工程化、路由、权限、接口封装和部署。

Vite 工程化

从浏览器 Babel 练习切换到真正项目结构，使用 npm、模块导入、打包构建。

React Router

把用户管理、订单管理、系统设置做成多页面路由，而不是多个独立 HTML。

接口封装

统一处理 baseURL、token、错误提示、loading、JSON 解析。

登录和权限

登录页、token 保存、菜单权限、按钮权限、未登录跳转。

组件库

学习 Ant Design 这类组件库，快速构建专业表单、表格、弹窗。

部署和规范

打包、环境变量、Nginx 或 Spring Boot 静态部署、代码目录规范。

阶段三什么时候开始

当你能不用看答案完成这些事情，就可以进入阶段三：

  • 自己拆出 Sidebar、UserForm、UserTable。
  • 自己写新增、删除、编辑、搜索、筛选。
  • 能解释清楚状态为什么放在父组件。
  • 能把本地数组替换成一个真实接口。
